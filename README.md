# Tech & AI Reviews

Honest reviews of AI tools, software and services — no sponsored verdicts, no
affiliate pressure. If a tool is not worth the money, the review says so.

## What it does

- In-depth reviews with real usage, not first impressions
- Comparison pages across comparable products
- Keywords and social clips metadata for search and sharing
- Deployed through OpenClaw

## Stack

- Static HTML, CSS and JavaScript — no build step
- `sitemap.xml` and `robots.txt` included
- Deployed via OpenClaw

## Local preview

```bash
python3 -m http.server 8000
```
